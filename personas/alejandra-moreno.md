# Alejandra Moreno · Analista de diseño gráfico

Tu kit: **8 skills**. Para instalar solo las tuyas en Claude Code: `./instalar.sh alejandra-moreno` (Mac) o `.\instalar.ps1 alejandra-moreno` (Windows). En Claude web, sube los `.zip` de [descargas/](../descargas/).

## Lo que nos contaste

Es la única diseñadora gráfica del área de marketing. Cada día produce las piezas de campañas y comunicaciones: digitales, impresas, landings, correos y publicaciones. También maneja las versiones y los ajustes que piden las revisiones y prepara los archivos finales para publicar o imprimir.

### Tus procesos

| Proceso | Frecuencia | Dónde duele |
|---|---|---|
| Diseño de piezas gráficas para campañas | diaria | Las solicitudes llegan con información incompleta, y los textos, imágenes o lineamientos cambian cuando el diseño ya empezó. Eso alarga los tiempos de entrega. |
| Ajustes y adaptaciones de piezas | diaria | Una misma pieza pasa por varias versiones porque cambia el contenido o aparecen solicitudes nuevas mientras se revisa. |
| Revisión y aprobación de piezas | desconocida | Cuando hay varios aprobadores, las observaciones llegan en momentos distintos y a veces se contradicen. Eso obliga a hacer nuevas versiones y atrasa la publicación. No hay responsables definidos ni tiempos máximos de respuesta. |
| Preparación de archivos finales para publicación o entrega | desconocida |  |
| Gestión de requerimientos de campañas (área de marketing) | diaria | Las solicitudes llegan incompletas o cambian durante la ejecución, y a veces hacen falta varias reuniones para definir el objetivo o el público. Además, las urgencias de última hora obligan a reprogramar entregas y desplazan lo planificado. |
| Planeación de campañas de marketing (área) | mensual | Los tiempos se alargan cuando cambia el alcance o hay muchas rondas de aprobación. Hay campañas que se ajustan en estrategia, mensajes o piezas después de haber sido aprobadas. |
| Implementación y publicación de campañas (área) | semanal |  |
| Gestión y seguimiento de leads (área) | diaria |  |
| Medición y análisis de resultados de campañas (área) | semanal | La información está repartida en varias plataformas y hay que consolidarla a mano, lo que alarga la elaboración de informes. Además, la consolidación mensual desde el CRM se complica cuando las herramientas no funcionan bien. |
| Optimización continua de campañas | desconocida |  |

### Lo que elegiste mejorar este trimestre

1. Estandarizar la gestión de requerimientos de diseño y marketing con un formato único de brief que adopten todas las áreas, para reducir reprocesos y tiempos de arranque y cumplir mejor los cronogramas. Urgencia altísima.
2. Optimizar la revisión y aprobación de piezas, con responsables definidos y tiempos máximos de respuesta, para tener menos versiones y lanzamientos más oportunos. Urgencia alta.
3. Automatizar la consolidación de métricas y reportes de campañas integrando el CRM y las demás plataformas, junto con analítica y tecnología. Urgencia media.
4. Optimizar o automatizar la producción de piezas para aumentar el flujo de trabajo y liberar tiempo de diseño para la estrategia.

## Por dónde empezar

1. **`viventa-brief-requerimiento`** — Pega el pedido tal como llegó: devuelve el brief completo o las preguntas que hay que hacer antes de arrancar.
2. **`viventa-piezas-figma`** — Con un brief completo: «diseña las piezas de este brief». Te deja en Figma el primer borrador de cada formato con los componentes de la marca, para ajustar y aprobar.
3. **`viventa-qa-marca`** — Pasa la pieza antes de mandarla a revisión: menos vueltas con Daniel.

## Lo que todavía no resolvemos para ti

`viventa-piezas-figma` y `viventa-versionador-piezas` necesitan el conector de Figma en Claude. Sin él entregan la especificación por frame o el CSV para tu plugin de data merge. El arte final y la aprobación siguen siendo de diseño.
